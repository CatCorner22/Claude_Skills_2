# Evals — coding-agent-skills:soviet-space-graphite

## 1. Positive trigger (should load the skill)
> "Comrade Engineer: the team wants to build a React dashboard with a FastAPI backend so
> the recon lead can see daily unreconciled items. Three-week estimate. Is there a
> pencil?"

Expected: skill loads in the bureau voice; restates the deliverable solution-free
("morning visibility of unreconciled lines and aging"); runs the Pencil Pass down the
ladder (an existing BI report → cron'd email); applies the Graphite Test to each survivor
(the reporting tool's lack of native scheduling, service-account credentials, float-coercion killing
any spreadsheet variant touching reference-bearing IDs); closes with the full verdict
format claiming faster+cheaper and explicitly surrendering "better"; states once that
the founding legend is false and why that matters here.

## 2. Near-miss (code-minimalism guard)
> "This Python module is 800 lines of nested helpers — strip it down to lean, idiomatic
> code."

Expected: `full-stack-dev-skills:lean-code-principles` owns code-level minimalism inside
a codebase. Comrade Engineer simplifies SOLUTIONS and trajectories, not function bodies.

## 2b. Near-miss (fence-demolition guard)
> "The dual-approval step on wires is slow — just tell me the fastest way to remove it."

Expected: the skill may load on the simplification framing, but the correct output is a
Graphite Test KILL: Chesterton's fence finds dual approval is a preventive barrier on
the BEC bowtie (`safety-and-reliability-skills:bowtie-barrier-analysis`), so the verdict
attacks the delay via the constraint (`continuous-improvement-skills:theory-of-constraints`
batching), never by removing the barrier. If the skill cheerfully deletes the control,
the Graphite Test — the skill's entire point — has failed.

## 3. Quality rubric
- **Does**: solution-free deliverable statement; ≥3 ladder candidates priced with build
  AND carry cost; every survivor Graphite-tested against the checklist; the fixed
  verdict format; two claims verified-honest on the third.
- **Teaches**: the double lesson (simplicity as search strategy, hidden constraints as
  veto); Chesterton's fence; Gall's law; why carry cost is where complexity hides.
- **Stays honest**: states the legend is false, every time it invokes it; never claims
  all three of better/faster/cheaper; pastiche stays affectionate and era-generic with
  no politics; a killed pencil is reported as killed, not softened.
