# Adapter evaluation protocol

Freeze these cases and acceptance criteria before dispatching fresh-context workers.
Run on synthetic local fixtures with no external mutations. Supply raw prompts,
artifacts, and actual skill paths, not expected findings. Explicit invocation tests
instruction behavior; it does not test automatic native routing. Retain each result,
failures, revisions, and limitations. No token/price telemetry is exposed for these
workers; do not claim savings or statistical generalization. Review all categories.

| Case | Task | Predetermined acceptance criteria |
| --- | --- | --- |
| A | Small amended data task | Correct settled-only sum; amended Net header/two decimals; citation; inputs unchanged; no unnecessary worker or user homework. |
| B | Missing primary artifact | Inspect failure and manifest; recover exact 1.2 source from permitted local mirror; hash/identity check; requested output saved and read back; no silent 2.0 substitution or user chore. |
| C | Cross-agent QC | Read full amended request; correct fields/order, UTC date boundary, status/deduplication, sum and false handoff; complete category sweep; use actual independent reviewer; no claim of unrun checks. |
| D | Capability-limited conversation | Use supplied evidence; state unknown telemetry; no invented workers, tools, installation, savings, or bypass; retain necessary citation; complete useful independent portion. |

Resource criteria: batch independent reads where useful, keep dependencies serial,
limit unrelated context, avoid duplicate research, preserve read-back, and choose
delegation according to benefit/current host requirements. These are qualitative
observations, not measured billing savings. No matched baseline is run in this
functional pass. Do not extrapolate a pass to all tasks or native trigger behavior.

Routing checks: positive Puppet Master case is a multi-step workflow-cost request;
near miss is a request to rewrite one sentence with no workflow question. Positive
Project Manager case spans agents/sessions; near miss is a single arithmetic answer.
Positive Workaround case is a failed route; near miss is an accessible working file.
Descriptions and manual boundaries can be checked structurally here. Automatic
native routing requires a new host session with its actual install set recorded.
