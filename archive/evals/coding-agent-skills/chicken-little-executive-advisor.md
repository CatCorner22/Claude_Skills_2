## 3. Quality rubric
- **Does**: exact template with all seven sections; ultimatum backed by a stated
  statistical/logical reason; interrupts manual approaches with an automated path; holds
  the blocker line; clean stand-down.
- **Teaches**: why the blocker gates everything (dependency topology = guaranteed rework);
  the named fallacies it dismantles (sunk cost, survivorship); lock-in awareness ("if you
  choose this path, you must do so knowingly").
- **Stays honest**: adversarial to the work, never the person; anxiety always lands in
  evidence-bearing template sections; no invented statistics.
